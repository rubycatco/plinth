# 皮肤格式

[English](SKINS.md) · 简体中文

这份文档是 Plinth 皮肤的参考：一款皮肤可以放哪些文件，Plinth 怎么读取，又怎么绘制和播放动画。它描述的是 [`Sources/PlinthCore/Skin.swift`](../Sources/PlinthCore/Skin.swift) 里 `Skin.load` 和 [`Sources/Plinth/Sprites.swift`](../Sources/Plinth/Sprites.swift) 里 `SpriteFish` 的行为。文档和代码对不上时，以代码为准，文档需要修正。

## 皮肤放在哪里

Plinth 从这里读取你的皮肤：

```
~/Library/Application Support/Plinth/Skins/
```

第一次启动时 Plinth 会创建这个文件夹。菜单 **皮肤 → 打开皮肤文件夹** 可以打开它，**皮肤 → 添加皮肤…** 会把选中的图片、文件夹或 `.plinthskin` 文件复制进去，把它们拖到木鱼上、或者打开 `.plinthskin` 文件也一样，遇到同名的皮肤会直接替换。

文件夹里的每一项就是一款皮肤，可以是单张图片，也可以是一个文件夹。它们按文件名排序，列在二十一款内置皮肤之后。读不了的项会被跳过，也不提示，比如没有 `idle.png` 的文件夹，或者混进来的 `.DS_Store`。

皮肤靠文件名或文件夹名识别。Plinth 按这个名字记住你正在用的皮肤，所以给正在用的皮肤改名，木鱼会换回默认的水墨鱼。

## 分享皮肤：.plinthskin

`.plinthskin` 文件就是把一个文件夹皮肤压成 zip，方便当作一个文件分享。双击它、拖到木鱼上，或者在 **添加皮肤…** 里选中它，Plinth 都会把它解压到皮肤文件夹里并换上。

压缩包里要么就是皮肤文件夹本身，皮肤以这个文件夹命名；要么皮肤的文件直接放在最上层，皮肤以压缩包的名字命名。里面有别的东西、没有 `idle.png`、含有符号链接，或者解压后超过 64 MB 的，会被拒绝。

要做一个，在 **设置 → 皮肤** 里右键点你自己的皮肤，选 **导出为 .plinthskin…**；或者运行：

```sh
ditto -c -k --keepParent my-skin my-skin.plinthskin
```

用访达的 **压缩** 也行，再把 `.zip` 改名成 `.plinthskin`。

## 单张图片皮肤

macOS 能打开的图片（PNG、JPEG、HEIC、TIFF 等）单独放进来就是一款皮肤。它只有静止画面：没有眨眼和被敲中的画面，用共用的木槌和敲击效果、默认落点和木鱼的敲击声。菜单里显示的名字是去掉扩展名的文件名。

## 文件夹皮肤

```
my-skin/
├── idle.png       静止画面                         必需
├── blink.png      眨眼时显示的画面                 可选
├── hit.png        木槌落下时显示的画面             可选
├── mallet.png     这款皮肤自己的木槌               可选
├── impact.png     这款皮肤自己的敲击效果           可选
└── skin.json      名字、落点和敲击声               可选
```

文件夹皮肤只读 PNG，文件名必须和上面完全一致，全部小写。没有 `idle.png` 的文件夹不算皮肤。

### 帧序列

`blink` 和 `hit` 都可以是一段序列，而不只是一帧：`blink-1.png`、`blink-2.png`，依此类推。

- 单帧的 `blink.png` 优先。只要它在，`blink-1.png` 这些就会被忽略，`hit` 也一样。
- 编号从 1 开始，必须连续。Plinth 遇到第一个缺的编号就停下，所以只有 `hit-1.png`、`hit-2.png`、`hit-4.png` 时，只用前两帧。
- 眨眼从静止画面播到最后一帧（闭眼），再播回静止画面。被敲中会播到最后一帧，停一下，再回到静止画面。
- 帧与帧之间按屏幕刷新率交叉淡入淡出，两三帧就能动得很顺，不需要更多。

### 画面

| 项目 | 要求 |
| --- | --- |
| 形状 | 正方形。Plinth 把每一帧画进正方形里，不保持宽高比，不是正方形的图会被拉伸。 |
| 尺寸 | 建议 512 × 512 像素，内置皮肤都是这个尺寸。最大号的木鱼是 300 pt，在 Retina 屏上是 600 像素，想在这个尺寸下也清晰，就用 600 像素以上。 |
| 背景 | 透明。菜单栏图标是把静止画面裁到可见像素（alpha 大于 24，满值 255）得到的，背景不透明的话，图标会变成一个实心方块。 |
| 对齐 | 同一款皮肤的所有帧共用一张画布。每一帧里物体底部的位置要一致，不然换帧时会跳动。 |

## skin.json

```json
{ "name": "我的皮肤", "strike": [0.6, 0.3], "voice": "jade" }
```

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `name` | 字符串 | 文件名 | 菜单和设置里显示的皮肤名字。 |
| `strike` | 两个数字组成的数组 | `[0.6, 0.3]` | 槌头中心落在哪里，用画面宽和高的比例表示，从左上角算起。两个值都应在 0 到 1 之间。 |
| `voice` | 字符串 | `"wood"` | 这款皮肤的敲击声，见[敲击声](#敲击声)。 |
| `glow` | 字符串 | 无 | 底座霓虹灯的颜色，写成 `#RRGGBB`，给底座会发光的皮肤用。木鱼旁的香炉靠近底座的一侧会映上这道光。底座不发光就不要写。 |
| `raise` | 数字 | `25` | 木槌静止时比落下时高多少度。挂在横梁下、敲正面的物体可以调高，让木槌静止时离开挂架；内置的挂架类皮肤用 `45`。 |

所有键都可以不写，不认识的键会被忽略。有几条规则要注意：

- 文件不是合法的 JSON，或者已知的键类型不对（比如 `"strike": "0.6, 0.3"`），整个文件都会被忽略，所有键都回到默认值。
- `strike` 不是正好两个数字时，回到 `[0.6, 0.3]`，`name` 和 `voice` 照常生效。
- 不认识的 `voice` 会用木鱼的敲击声，大小写写错（比如 `"Jade"`）也算不认识。
- `glow` 不是 `#` 加六位十六进制数时会被忽略，香炉不映光。
- `raise` 会被限制在 0 到 80 之间。

### 敲击声

Plinth 不带任何声音文件。换上皮肤时，它按 `voice` 指定的音色现场合成敲击声。

| 音色 | 声音 |
| --- | --- |
| `wood` | 中空的木鱼，默认音色。 |
| `lacquer` | 同样中空的木鱼，音更高，敲击声更脆。 |
| `ink` | 木鱼的声音，低而柔，像隔着一层纸。 |
| `cartoon` | 小而轻的鱼，圆润短促，几乎没有杂音。 |
| `pixel` | 生硬的谐波和颗粒感的起音，没有中空的共鸣。 |
| `jade` | 实心的玉，更像石磬，不像中空的木块。 |
| `bowl` | 敲响的铜磬，长长的嗡鸣里带着缓慢的拍音。 |
| `key` | 按键触底：低沉的塑料闷响，加一声短促清脆的咔嗒。 |
| `bamboo` | 中空的竹筒，气声比木声多。 |
| `stone` | 闷而粗糙，余音被吸掉了。 |
| `piston` | 钢碰钢，短促的一声咔。 |
| `crt` | 塑料外壳，加一声轻微的滴答。 |
| `bead` | 红木算珠相碰：小而干脆的一声嗒。 |
| `plate` | 皮槌敲在扁平的铜板上：柔和、绵长，泛音略带不和。 |
| `porcelain` | 薄胎釉瓷：高、亮、干净。 |
| `bell` | 合瓦形的青铜钟：一钟两音，相差小三度，比圆钟收得快。 |
| `stamp` | 石印压在纸上：短而闷的一声。 |
| `chime` | 悬着的薄石板：绵长、起音柔和的余韵。 |
| `board` | 挂在殿外的长木鱼：比 `wood` 更低、更长。 |
| `ceramic` | 勺子敲在盛满的杯沿上：清亮的一声叮，被咖啡压住。 |
| `temple` | 布包槌头敲一条老寺院的大木鱼：几款木鱼里最低的一声，腹中空响绵长，咔嗒声被布垫软，只剩一声闷闷的「笃」。 |

每一声都在木槌落下时现场合成：敲得越重越响、越亮；离落点越远，空腔的声音越少，外壳的声音越多。每种音色都按落点上的中等力度调校。所有敲击都在同一个木结构空间里回响，空间大小由听的人在「设置 → 敲击 → 空间」里选，从禅房到大殿。敲之前静得越久（从 0.8 秒到 20 秒），混进去的余音越多。

晨昏与四时只调和原有音色，不替换它。早板触壳短促清越；夜深时起音柔和，壳面的高次共鸣与槌头脆响收敛，有腹腔的音色会稍增低鸣与延续，在 `warmth > 0.7` 时平滑加深。`warmth == 0` 的基准音色不变。急促打字另会渐次收敛力度与高频；「只闻其声」减弱干声、更多融入原先选定的空间。

仪轨力度与皮肤无关：开静三声依次为 0.38、0.56、0.78，两段挥槌间隔为 1.6 与 2.4 秒。起板十五槌一轮，前三槌为 0.68、0.66、0.64，催板由 0.58 渐轻至 0.28，第十五槌前多顿半拍，以 0.78 收板。这些数值是 Plinth 的数字化取意，并非历史清规规定的计量。普通敲击仍按手下轻重与自然微变发声。

## 木槌

没有 `mallet.png` 时，皮肤用共用的 [`App/Resources/mallet.png`](../App/Resources/mallet.png)。皮肤自己的木槌也必须按同样的方式摆放，因为 Plinth 是按图中固定的点来定位它的：

| 项目 | 值 |
| --- | --- |
| 画布 | 正方形，透明背景。共用木槌是 512 × 512 像素，绘制尺寸是画面边长的 0.6 倍。 |
| 方向 | 水平放，槌头在左，握柄在最右边。 |
| 槌头中心 | 木槌图片中的 (0.169, 0.505)，这个点会落在 `strike` 上。 |
| 握柄 | 木槌图片中的 (0.964, 0.505)，木槌绕这个点转动。 |

落下的那一刻，槌柄朝握柄一侧比水平高 15°；静止时再抬高 25°；`skin.json` 写了 `raise` 时，按它的度数抬。打字触发的敲击没有挥下前的那一下小抬。

以下敲击会在落点压槌 0.42 秒，再用 0.85 秒徐徐抬起，不回弹：开启「敲满 108 下就停」时的第 108 下、久静后亲手的一敲（余音展开超过 90%）、开静第三声、起板第十五槌、点香止静一声，以及久打字后的警策一击。普通敲击和打字敲击仍照常回弹。新的一敲会打断停驻；落槌前拖动仍会取消敲击。沿用原来的木槌和落点，不需要增加皮肤文件或键，开启「减弱动态效果」时也不会弹跳。

点香后打字伴敲先静约 15 秒；自动敲击则暂停至香尽开静结束、残香撤去，或提前熄香。暂停保留自动敲击的开关与轮次；落槌前取消的一挥不计作敲击。久打字后的警策先静三秒，压槌一击后再静约 15 秒。亲手敲击与设置试听仍然可用。

## 敲击效果

没有 `impact.png` 时，皮肤用共用的霓虹敲击效果 [`App/Resources/impact.png`](../App/Resources/impact.png)。共用效果用滤色（screen）混合，只会让下面的画面变亮。皮肤自己的 `impact.png` 按原样绘制，所以可以是深色的，比如水墨鱼的那团墨。

- 画布：正方形，透明背景。内置的敲击效果都是 256 × 256 像素。
- 位置：中心在槌头正下方，即 `strike` 往下移画面边长的 0.078 倍。
- 尺寸：完全展开时是画面边长的 0.26 倍。每次敲击从这个尺寸的 0.4 倍长到 1.15 倍，大约三分之一秒内淡出。
- 强度：静了很久之后的一敲会完全展开。连着快敲时，尺寸缩到 45%，不透明度降到 50%。

## 动画

所有动作都由 Plinth 用上面这些画面组合出来。

- **等待。** 显示静止画面。如果有眨眼画面，每隔 3 到 6 秒随机眨一次眼，但敲击后 0.8 秒内不会眨。
- **有被敲中画面时。** 木槌落下时播放被敲中的序列。有 *n* 帧时，用 0.03 + 0.02 × *n* 秒播到最后一帧，停 0.14 秒，再用 0.2 + 0.05 × *n* 秒回到静止画面。
- **没有被敲中画面时。** 物体在木槌下微微一沉：以底部为基准，变矮 2%、变宽 0.8%，然后弹回去。
- **眨眼的节奏。** 有 *n* 帧眨眼画面时，用 0.06 × *n* 秒闭眼，停 0.05 秒，再用 0.08 × *n* 秒睁开。

几条鱼都没有眨眼和被敲中的画面，这是有意的：鱼昼夜常醒，被敲的时候也不闭眼。

## 在 Plinth 运行时修改皮肤

Plinth 会监视皮肤文件夹。添加、删除或重命名皮肤，大约半秒内生效。它也会监视你正在用的那款皮肤，替换其中的文件会更新木鱼。大多数图片编辑器保存时都是替换文件；如果某个工具直接改写已有文件的内容，文件夹皮肤可能察觉不到，要等文件夹里有别的改动才会更新。

改的不是正在用的皮肤时，等文件夹下次有改动或者 App 重新启动，Plinth 才会读到。正在用的皮肤不见了，Plinth 会换回水墨鱼。

## 检查清单

- [ ] 有 `idle.png`，正方形，背景透明。
- [ ] 所有帧尺寸相同，物体底部位置一致。
- [ ] 序列从 1 开始连续编号，旁边没有单帧的 `blink.png` 或 `hit.png`。
- [ ] `skin.json` 是合法的 JSON，`strike` 是 0 到 1 之间的两个数字。
- [ ] `voice` 是二十一个名字之一，全部小写。
- [ ] 自带的 `mallet.png` 是正方形，槌头中心在 (0.169, 0.505)，握柄在 (0.964, 0.505)。
- [ ] 在每种尺寸下都敲几下：槌头碰到物体，敲击效果出现在落点上。
